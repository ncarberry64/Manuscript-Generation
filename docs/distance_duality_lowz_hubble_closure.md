# Distance-duality and low-z Hubble closure

Two observable relations are fixed without new BHSM action coefficients.

## Exact fixed-z distance duality

Under Etherington reciprocity,

delta D_A / D_A = delta D_L / D_L,

so

F_DA(z) = F_DL(z).

F_DA is therefore not an independent kernel under the standard optical
assumptions.

## Low-z Hubble relation

As z -> 0,

D_L = cz/H0 + O(z^2),

hence

delta H0/H0 = -delta D_L/D_L + O(z).

Using A_mu=-0.0412 +/- 0.009 gives

delta D_L/D_L = -0.0189733 +/- 0.0041447,

delta H0/H0 = +0.0189733 +/- 0.0041447.

For H0=67.4 km/s/Mpc this is

delta H0 = 1.279 +/- 0.279 km/s/Mpc.

This is a low-z corollary, not the full F_H(z) kernel.
