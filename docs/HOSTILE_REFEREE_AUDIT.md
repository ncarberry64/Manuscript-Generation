# Hostile-referee audit

Scope: final Universe preparation pass. This is an internal skeptical review, not independent peer review. CLOSED means the stated documentary/mathematical objection is addressed within its assumptions; it does not certify the whole theory.

| Objection | Status | Evidence and remaining requirement |
|---|---|---|
| This is standard Schur reduction and constrained perturbation theory | PARTIALLY CLOSED | Introduction and Methods explicitly disclaim novelty of these operations. The proposed contribution is the integrated audited cosmological chain. Its scientific significance remains for referees to judge. |
| BHSM provenance of n=2 is assumed | PARTIALLY CLOSED | Regular closed-FLRW harmonic exclusion is explicit and cited. The BHSM boundary-sector identification is conditional. Existing `bhsm_native_cosmology_bridge.md` lists upstream PR numbers but lacks complete immutable action exports and bibliographic provenance. |
| Two state dimensions are not action-owned | OPEN | One selected profile has a canonical pair, but n=2 has nine angular harmonics; selecting a profile/axis and freezing its population requires independent physics. It is not a theorem that the full BHSM scalar sector has only two coordinates. |
| Calibration has been presented as prediction | CLOSED | One SN amplitude has rank one on a two-dimensional state; growth/Weyl rows vary on its null direction. R1 parameters/axis remain calibrated or conditional. Gate A is a two-parameter consistency fit, not an additional absolute calibration. |
| A single local source type does not imply rank-one integrated covariance | CLOSED | Main theorem now states finite global latent-amplitude assumption and a rank-two path-increment counterexample. Physical derivation of separability remains OPEN. |
| The covariance-rank null is unobservable without isolating C_topo | OPEN | Raw survey covariance is not the target. Independent standard/noise models and source matching are required; no survey-specific design is frozen. |
| Astrophysical covariance subtraction can force rank one | FATAL IF UNRESOLVED | A decisive data claim requires independently constrained nuisance models, full uncertainty propagation and no clipping. The new code retains signed eigenvalues. Existing clipping helper is historical only. |
| Fixed Gaussian simulations do not test a composite rank-one null | CLOSED | API, manuscript and protocol explicitly restrict the benchmark to independently fixed covariance/loading. A composite likelihood or survey-calibrated bootstrap remains to be supplied before real rejection. |
| Look-elsewhere effects, bin selection and multiple gates | PARTIALLY CLOSED | Axis, bins, kernels and channel count may not change after inspection. Separate 1% gates have at most 2% either-gate size; no statistical independence assumed. Target-specific multiplicity remains to be frozen. |
| Target datasets are not independent | OPEN | Pantheon+ and repeated 2MRS proxies are development/calibration evidence. Shared sky, sample overlap and cross-survey covariance must be modeled in a future target design. |
| Angular axis is fitted and coordinate conventions are unclear | PARTIALLY CLOSED | Carried-forward equatorial RA 211.48 deg, Dec -12.81 deg is fixed prospectively. ICRS conversion and source/target selection must be certified in target design; historical axis likelihood is not rerun here. |
| Gauge invariance is merely asserted | PARTIALLY CLOSED | Fixed-observed-redshift formula, observer/source velocity terms, ADM dictionary and algebraic constraint checks are explicit. Independent full light-cone reproduction and complete matter/radiation backreaction remain open. Equal distance-duality rows alone are not an independent gauge test. |
| Curvature or Weyl signs have been mixed | PARTIALLY CLOSED | Positive K and negative Omega_k; n versus N convention and conventional versus positive-spatial-potential Weyl signs are identified. Conformal chi optical derivatives are distinguished from physical affine derivatives. A full external convention audit is still valuable. |
| Observational selection can manufacture extra eigenmodes | FATAL IF UNRESOLVED | A real Gate B claim needs matching, masks, calibration systematics, intrinsic alignments and correlated sampling in the null simulation. No empirical gate result is claimed. |
| Absolute source normalization is absent | OPEN | Compact full-preimage background, local matrix elements, seam export and rare events are explicit upstream gaps. Fatal to an ab initio cosmology claim, but not to the conditional algebraic results presented here. |
| Parameter counting ignores auxiliary metric/optical states | PARTIALLY CLOSED | Metric is a constrained response, optical state has fixed bundle boundary data. Two profiled temporal coordinates are counted; profile/axis/source assumptions and fixed nuisance inputs are listed separately. |
| Low-energy derivative expansion is extrapolated to high n | PARTIALLY CLOSED | Discussion now separates illustrative polynomial filter from a controlled large-n result of the exact complement. UV completion and full stability are OPEN. |
| Curved-EFT failure might be an implementation defect | OPEN | One strict xfail records the specific preservation failure. This cannot support a general claim against EFT/QFT or prove superiority of BHSM. |
| Failed homogeneous localization is not independently reproducible here | OPEN | Prior report is retained in `bhsm_los_topographic_transfer.md`; its exact statistic, threshold and original machine-readable result are missing. New manuscript explicitly labels the result reported rather than revalidated. |
| Foreground negative results are overinterpreted | PARTIALLY CLOSED | All three artifacts retain not_established classifications and worse held-out chi-square. This rejects transfer usefulness under the specified controls, not all foreground physics. Exact original derived-input hashes remain missing. |
| Preprint relationship or text reuse is hidden | PARTIALLY CLOSED | Verified Preprints.org title/identifier are cited; cover letter explains expansion. User-supplied later title differs and requires author reconciliation. No independent similarity report has been obtained. |
| No near-term testability before named survey releases | PARTIALLY CLOSED | Shared-state and covariance estimators can be exercised on synthetic data and future independently designated public/held-out products. No claim that a particular future release guarantees adequate joint coverage or power. Power study and target eligibility remain OPEN. |

The package can support evaluation of a conditional methodological paper. It is not evidence of complete BHSM closure, a successful blind observational test, or an author-approved submission. Do not remove these objections merely to obtain a favorable readiness label.
