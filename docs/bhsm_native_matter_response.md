# BHSM-native matter response

## Theorem

Given the induced BHSM metric response h_2=R_g2 X_2, dust and radiation obey a
forced linear conservation system

Y_m' = A_m Y_m + S_m R_g2 X_2.

Variation of constants gives

Y_m(N)
= U_m(N,N_i)Y_m(N_i)
+ integral U_m(N,N') S_m(N') R_g2(N') X_2(N') dN'.

For a fixed branch initial-data prescription this defines the history operator
R_m2.

## Consequence

The complete physical response is

R_2 = (R_g2, R_m2)^T,

and every scalar linear observable is

A_O(z) = L_O,z R_2(z) X_2.

The metric, matter, distance, growth and lensing dipoles therefore share the
same one-mode axis at linear order.

Evaluate the already-defined reduced operators on the frozen R1 branch.  This
is a normalization/evaluation problem, not an unresolved mode-count problem.
