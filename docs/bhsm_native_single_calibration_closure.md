# BHSM-native single-calibration closure

## Theorem

For one normalized physical n=2 mode,

A_O(z) = A_2 F_O(z).

One nonzero calibration therefore fixes

A_2 = A_C^obs(z*) / F_C(z*),

and predicts every other linear observable:

A_O(z)
= A_C^obs(z*) F_O(z) / F_C(z*).

No independent anisotropic amplitude remains for H, D_A, growth or lensing
once the branch and one calibration are frozen.
