\section{Matter-Sourced Constraint Transfer at n=2}

The Round-3 kernel established the pure gravity--scalar constrained dynamics of the first physical closed-universe harmonic. The next step is to introduce minimally coupled matter sources without importing a flat-space or quasi-static approximation. We use the curvature-aware Newtonian-gauge EFT equations written by Gambino and Pace \citep{GambinoPace2024}. Their metric convention is
\[
ds^2
=
-(1+2\Phi)dt^2
+
a^2(1-2\Psi)\gamma_{ij}dx^idx^j,
\]
with
\[
\delta T^0{}_0=-\delta\rho,
\qquad
\delta T^0{}_i=(\rho+p)D_i v.
\]

For the present cubic-Galileon subclass,
\[
\alpha_M=\alpha_T=\alpha_H=0,
\qquad
M^2=M_{\rm Pl}^2.
\]
The curvature-aware equations use the Gleyzes/Gambino--Pace braiding normalization. To distinguish it from the Bellini--Sawicki braiding function used in the previous sections, we write
\[
\boxed{
\alpha_B^{\rm GP}
=
-\frac12\alpha_B^{\rm BS}
}.
\]
The kineticity is unchanged,
\[
\alpha_K^{\rm GP}=\alpha_K^{\rm BS},
\]
and therefore
\[
\alpha_K+6(\alpha_B^{\rm GP})^2
=
\alpha_K+\frac32(\alpha_B^{\rm BS})^2
=
D_{\rm kin}.
\]
For ideal dust and ideal radiation we set the scalar anisotropic stress to zero, so the traceless spatial equation gives
\[
\boxed{\Phi=\Psi}.
\]

On the physical \(n=2\) harmonic,
\[
D^2Q=-8KQ,
\qquad
(D^2+3K)Q=-5KQ.
\]
Writing
\[
\kappa=\frac{K}{a^2},
\]
the sourced \(00\) equation becomes
\[
6(1+\alpha_B^{\rm GP})H\dot\Phi
+
(\alpha_K-6\alpha_B^{\rm GP})H^2\dot\pi
+
\left[
(6-\alpha_K+12\alpha_B^{\rm GP})H^2
+
10\kappa
\right]\Phi
\]
\[
+
6H
\left[
\frac{\rho+p}{2M_{\rm Pl}^2}
+
\dot H(1+\alpha_B^{\rm GP})
+
\kappa\left(1-\frac83\alpha_B^{\rm GP}\right)
\right]\pi
=
-\frac{\delta\rho}{M_{\rm Pl}^2}.
\]

The \(0i\) equation is
\[
2\dot\Phi
-
2H\alpha_B^{\rm GP}\dot\pi
+
2(1+\alpha_B^{\rm GP})H\Phi
+
\left(
2\dot H+\frac{\rho+p}{M_{\rm Pl}^2}
\right)\pi
=
-\frac{q}{M_{\rm Pl}^2},
\]
where
\[
q
=
\rho_m v_m
+
\frac43\rho_r v_r,
\qquad
\delta\rho
=
\rho_m\delta_m+\rho_r\delta_r.
\]

These equations form a \(2\times2\) local constraint-transfer system for
\[
(\dot\Phi,\dot\pi).
\]
Its determinant is
\[
\boxed{
\det\mathcal C
=
-2H^2
\left[
\alpha_K+6(\alpha_B^{\rm GP})^2
\right]
=
\boxed{-2H^2D_{\rm kin}}.
}
\]
Thus the same positive-\(D_{\rm kin}\) branch used in the background and Round-3 kinetic audit guarantees that this sourced rate block is nonsingular.

For the velocity convention above, covariant conservation gives
\[
\dot\delta_m
=
\frac{k^2}{a^2}v_m
+
3\dot\Phi,
\qquad
\dot v_m=-\Phi,
\]
and
\[
\dot\delta_r
=
\frac43\frac{k^2}{a^2}v_r
+
4\dot\Phi,
\qquad
\dot v_r
=
-\Phi-\frac14\delta_r,
\]
with
\[
\frac{k^2}{a^2}=8\kappa.
\]

The repository implements these equations as a local linear transfer matrix with the additional topographic response explicitly switched off. This is deliberately not yet promoted to a globally integrated observable solution. The curvature-aware EFT equations and the Round-3 ADM kernel use different perturbation variables and normalizations; the remaining evolution equations must first be matched analytically and then subjected to a Bianchi/constraint-preservation audit. Only after that compatibility gate is passed will we integrate the full matter-era \(n=2\) system and add the independent reduced topographic operator.
