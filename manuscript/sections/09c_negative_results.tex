\section{Results: rejected and unestablished mechanisms}
\label{sec:negative-results}
The homogeneous two-state response fails the retained localization
criterion: state-direction selection does not supply the required
low-redshift confinement. The retained development report is
\path{docs/bhsm_los_topographic_transfer.md}.
The exact original localization statistic and threshold have not been
archived here; this is a reported prior failure, not a newly reproduced
quantitative rejection in this package.
This rejects that mechanism, not every possible sourced response.

Using the 2MRS release \citep{Huchra2012}, three frozen foreground proxies also fail held-out transfer.
The existing results, without refitting, are:

Each uses 277 supernovae; the number-density catalog has 38600 galaxies,
the photometric variants 38601. The latter have 83 calibration and 194
held-out supernovae. These are related development tests, not independent
detections. Their permutation values test improvement, not covariance rank.
Velocities, lensing and selection remain possible contaminants. None of
these proxies establishes an action-normalized local source.
