\section{Representation-invariant numerical bridge}
\label{sec:representation-invariant-bridge}

The retained-action provenance program and the effective four-dimensional
response calculation serve different purposes.  The former determines
whether the physical mode is selected by the BHSM parent action.  The latter
provides a practical representation in which the already-defined physical
two-dimensional mode can be propagated through a cosmological background.

A numerical effective representation is admissible only if it is a change of
coordinates on the same physical phase space rather than the introduction of
a second scalar degree of freedom.

\subsection{Phase-space equivalence}

Let
\begin{equation}
X_2
=
\begin{pmatrix}
q_2\\
\Pi_2
\end{pmatrix}
\end{equation}
denote the BHSM-native physical state, and let
\begin{equation}
Z_2
=
\begin{pmatrix}
\zeta_2\\
\Pi_{\zeta,2}
\end{pmatrix}
\end{equation}
denote an effective closed-Horndeski representation of the same mode.
Suppose
\begin{equation}
\boxed{
X_2=U(z)Z_2,
\qquad
\det U(z)\ne0.
}
\label{eq:XUZ}
\end{equation}

\paragraph{Theorem 12 (representation invariance).}
If the reduced quadratic operator, metric response and observation functional
are transformed by the same invertible map $U$, then all linear physical
observables are invariant.

\paragraph{Proof.}
If
\begin{equation}
S_2^{(2)}
=
\frac12 X_2^\dagger\mathcal K_2X_2,
\end{equation}
then Eq.~\eqref{eq:XUZ} gives
\begin{equation}
S_2^{(2)}
=
\frac12
Z_2^\dagger
\left(
U^\dagger\mathcal K_2U
\right)
Z_2.
\end{equation}
Thus
\begin{equation}
\mathcal K_{2,Z}
=
U^\dagger\mathcal K_2U.
\end{equation}
Likewise,
\begin{equation}
h_2
=
\mathcal R_{g2}X_2
=
\mathcal R_{g2}UZ_2,
\end{equation}
so
\begin{equation}
\mathcal R_{g2,Z}
=
\mathcal R_{g2}U.
\end{equation}
For any linear observation functional
$\mathcal L_{\mathcal O}$,
\begin{equation}
\delta\mathcal O
=
\mathcal L_{\mathcal O}\mathcal R_{2}UZ_2.
\end{equation}
The observable is therefore unchanged.  Since $U$ is invertible, the physical
phase-space dimension is unchanged. \hfill$\square$

\subsection{Numerical consequence}

The theorem permits the exact closed-Horndeski $n=2$ scalar kernel already
derived for R1 to be used as an \emph{effective response representation} of
the BHSM-native mode, provided the following matching conditions are checked:

\begin{enumerate}
\item both descriptions contain exactly one physical scalar mode, hence a
      two-dimensional phase space;
\item the state map $U(z)$ is nonsingular over the integration interval;
\item kinetic signs and mode normalization are mapped consistently;
\item lapse/shift constraint solutions are those of the physical $n=2$
      harmonic rather than the exceptional $n=1$ sector;
\item the same supernova calibration is transported through $U$ without a
      second amplitude fit.
\end{enumerate}

No claim is made that the effective Horndeski field is an additional BHSM
fundamental field.
