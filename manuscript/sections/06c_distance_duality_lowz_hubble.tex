\section{Exact distance-duality and low-redshift Hubble corollaries}
\label{sec:distance-duality-lowz}

Two parts of the five-kernel closure set can be reduced further without
evaluating a new action matrix element.

\subsection{Distance-duality corollary}

Assume photons propagate on null geodesics and photon number is conserved, so
Etherington reciprocity holds:
\begin{equation}
D_L(z,\hat{\mathbf n})
=
(1+z)^2 D_A(z,\hat{\mathbf n}).
\end{equation}
At fixed observed redshift,
\begin{equation}
\boxed{
\frac{\delta D_A}{D_A}
=
\frac{\delta D_L}{D_L}.
}
\label{eq:fractional-distance-duality}
\end{equation}

\paragraph{Corollary 10.1.}
For the same physical $n=2$ mode and the same fixed-redshift observation
functional,
\begin{equation}
\boxed{
\mathcal F_{D_A}(z)
=
\mathcal F_{D_L}(z).
}
\label{eq:FDA-equals-FDL}
\end{equation}
Thus $D_A$ is not an independent numerical kernel under the stated optical
assumptions.

\subsection{Low-redshift Hubble corollary}

The luminosity-distance cosmographic expansion is
\begin{equation}
D_L(z,\hat{\mathbf n})
=
\frac{cz}{H_0(\hat{\mathbf n})}
\left[
1+\mathcal O(z)
\right].
\end{equation}
Therefore
\begin{equation}
\boxed{
\frac{\delta H_0}{H_0}
=
-
\frac{\delta D_L}{D_L}
+
\mathcal O(z).
}
\label{eq:lowz-hubble-distance}
\end{equation}

Using the carried-forward reference supernova calibration
\begin{equation}
A_\mu^\star=-0.0412\pm0.009
\end{equation}
and
\begin{equation}
\frac{\delta D_L}{D_L}
=
\frac{\ln 10}{5}A_\mu ,
\end{equation}
gives
\begin{equation}
\boxed{
\left(
\frac{\delta D_L}{D_L}
\right)_\star
=
-0.0189733\pm0.0041447
}
\end{equation}
and hence the low-redshift Hubble anisotropy
\begin{equation}
\boxed{
\left(
\frac{\delta H_0}{H_0}
\right)_\star
=
+0.0189733\pm0.0041447 .
}
\label{eq:lowz-H0-fraction}
\end{equation}

For the illustrative reference value
$H_0=67.4\,{\rm km\,s^{-1}\,Mpc^{-1}}$, this corresponds to
\begin{equation}
\boxed{
\delta H_0
=
1.279\pm0.279\,
{\rm km\,s^{-1}\,Mpc^{-1}} .
}
\label{eq:lowz-H0-kms}
\end{equation}

\subsection{Claim boundary}

Equation~\eqref{eq:FDA-equals-FDL} is exact only under the standard
distance-duality assumptions and at fixed observed redshift.

Equation~\eqref{eq:lowz-hubble-distance} is a low-redshift cosmographic
statement.  It does not determine the full redshift-dependent
$\mathcal F_H(z)$ kernel.  Peculiar velocities, local structure,
survey-selection effects and other line-of-sight terms must be treated in
the data analysis rather than absorbed into a second anisotropic amplitude.

The consequence for the finite closure set is that the genuinely independent
full-redshift kernels are reduced from five to four:
\begin{equation}
\mathcal F_{D_L},\qquad
\mathcal F_H,\qquad
\mathcal F_{f\sigma_8},\qquad
\mathcal F_{\rm lens},
\end{equation}
with $\mathcal F_{D_A}$ inherited from
Eq.~\eqref{eq:FDA-equals-FDL}.  In the $z\to0$ limit,
$\mathcal F_H=-\mathcal F_{D_L}$.
