# What the Blackhole Tracker now establishes

The idea is to infer a compact dark object's surroundings from how it changes background light. Ordinary lensing already tracks dark masses. The new work asks whether a BHSM-organized envelope model predicts an additional linked pattern that can be separated from ordinary lens structure.

We now have a conditional mathematical pipeline from one explicit effective action and a normalized exterior deformation to image shifts, relative brightness and arrival-time differences. It uses one gravitational response throughout, avoiding a second count of the same mass/envelope contribution.

There is an instructive surprise: the leading screened deformation can move images and change their brightness while leaving the leading two-image time-delay change zero. A commonly useful mass estimate made from delay and brightness can also mistake that deformation for ordinary external shear. Keeping the separate image, brightness and timing data recovers information that the mass statistic discards. A synthetic calculation demonstrates that for a declared lens family, even while fitting unknown source positions, lens motion, ordinary quadrupoles, the scalar flux and the visible axial deformation.

This is not yet a practical black-hole detector. A deliberately small, controlled state produces a very faint response. The broad scan used to test mathematical separation would require millions of years of ordinary transverse motion for the cosmological example. A ten-year scan has severe degeneracies. Nor does the current calculation identify a horizon: it describes the exterior of a candidate compact dark mass.

The searched scientific record supplied the effective action and genuine boundary machinery, but did not establish the missing horizon/cosmological map selecting the scalar flux and deformation dynamics. It also did not select the example's physical amplitude. Those are specific next physical inputs, not claims that the work was never derived anywhere.

**Assessment:** the Blackhole Tracker is a defensible conditional theory/methods direction with concrete transfer formulas, useful failure tests and reproducible results. The evidence does not yet justify calling it a home run or an observational breakthrough. This manuscript makes the case accurately and shows what must be solved next.
